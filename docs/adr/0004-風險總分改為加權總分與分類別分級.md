# ADR-0004：風險總分改顯示加權總分，分級改由各設立別自己切

| | |
|---|---|
| 日期 | 2026-09-12 |
| 狀態 | 已採納 |
| 影響 | `model/scoring.py`、`model/score.py`、`backend/schemas.py` Risk、前端單園分析頁；取代 ADR-0001 註記中「分數用組內百分位」那一半 |

## 問題

### 一、畫面上的「風險總分」不是加權總分

`risk.score` 過去是**同儕群內百分位**（ECDF by peer_group），而畫面把它
擺在四維度加權明細的正上方：

```
風險總分  100.0  高風險
─────────────────────
違規   76.0 × 38.0%
評鑑   88.9 × 62.0%
```

76.0 × 0.38 + 88.9 × 0.62 = **84.0**，不是 100.0。稽查人員看到的是一個
「自己算不出來」的數字。落差還隨名次擴大：

| 全市名次 | 舊版顯示（百分位） | 加權總分 | 差 |
|---|---|---|---|
| 1 | 100.00 | 84.0 | 16 |
| 61 | 93.05 | 42.7 | 50 |
| 200 | 79.64 | 29.3 | 50 |

第 200 名顯示「79.6」，會被讀成接近滿分的危險，實際加權只有 29.3。
而 100.0 只是「同類中排第一」的另一種寫法——頁面上方兩行就已經寫著
「全市第 1 名」與「私立同類中前 0.0%」，三個數字說的是同一件事。

### 二、分級用全市合併排序，公立園永遠標不上高風險

公立園的加權總分分佈整體低於私立（基準被罰率 5.9% vs 12.5%）。
全市合併取前 50 名，名額幾乎全被私立佔滿，一間相對同類已經很糟的
公立園仍然顯示「低風險」。標籤要回答的是「這間園在同類裡算不算糟」，
不是「在全市排第幾」——後者已經由名次回答了。

## 決定

**分數、名次、分級三者各自對應一個問題，不再混用同一把尺。**

| 欄位 | 語意 | 計算 |
|---|---|---|
| `risk.score` | 這間園的風險量值 | **＝ R_raw**（四維度加權總分，取一位小數） |
| `risk.rank` | 全市排第幾 | 全市在營園所依 R_raw 合併排序（**不變**） |
| `risk.peer_rank` / `peer_n` | 同類中排第幾 | 設立別內依 R_raw 排序 |
| `risk.tier` | 這間園在同類裡算不算糟 | **各設立別**依自己的 R_raw 分佈切三段 |

分級的切點比例**從 `etl.constants.TIERS` 推導**，不寫死：以全市在營園數
為分母算出各級累積比例（50 / 1,178、200 / 1,178），再乘上該設立別的園數。
改 TIERS 時各類別的切點會跟著動。

實測切出來：

| 設立別 | n | 高 | 中 | 低 |
|---|---|---|---|---|
| 公立 | 290 | 12 | 37 | 241 |
| 私立 | 835 | 35 | 107 | 693 |
| 非營利 | 53 | 2 | 7 | 44 |
| **全市** | 1,178 | **49** | 151 | 978 |

## 不變的部分

- **派工單與回測仍是全市合併**。稽查人力是全市共用的固定資源，每週 50 個
  名額不按設立別配額；`Precision@50` 的定義因此完全不變，實測仍為
  **26.0%（lift 2.39x）**，門檻照樣通過。
- **子指標百分位仍在設立別內計算**（SPEC §5.2）。違規／評鑑／輿情三個維度
  的可得性不隨組織形態變化，這一層沒有動。
- 已停辦的 37 園仍是 `score`／`rank`／`tier` 三個都 null。

## 取代了什麼

`docs/營運係數.md` 整合表第 1 列寫的是「分數用組內百分位，分級用全市合併
排序取前 50 / 51–200」。前半段作廢——分數改成加權總分本身；後半段一半保留
——**名次與派工單**仍是全市合併，只有**分級**改成分類別。

該列當初否決的是「分級 = 各類型組內**前 15%**」，理由是前 15% 會選出 182 園、
對應不到 50 個稽查名額。本 ADR 不重蹈：分級與名額脫鉤（名額仍由全市前 50 決定），
而分類別的切點比例沿用 50 / 1,178，全市高風險總數維持在 49 園。

## 後果

- 前端移除了「同類中前 X%」那一行（`100 - score` 只有在 score 是百分位時
  才成立）與「加權總分」補充列（headline 就是加權總分，重複）。
  改以「全市名次 61 / 1,178　私立同類 59 / 835」兩把尺並列呈現。
- `meta.json` 新增 `tier_basis` 與 `tiers_by_type`，讓拿舊的「高風險 = 50 園」
  去對帳的人立刻看到實際數量是 49。
- 同一個分數在不同設立別可能得到不同標籤——例如加權總分 42.6 的公立園是
  高風險（公立同類第 3/290），42.7 的私立園是中風險（私立同類第 59/835）。
  這是刻意的，也是本 ADR 的目的。
