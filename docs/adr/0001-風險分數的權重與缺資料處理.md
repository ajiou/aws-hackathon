# ADR-0001：風險分數的權重、輿情維度與缺資料處理

| | |
|---|---|
| 日期 | 2026-09-12 |
| 狀態 | 已採納，待團隊確認 |
| 影響 | `SPEC.md` §5.0 權重表、§5.1 覆蓋率加權、§5.5 輿情維度、§6.3 門檻 |
| 提出 | A 軌（資料與模型）實作時量測發現 |

## 背景

照 `SPEC.md` §5 原文實作出來的 v2，**Precision@50 = 20.0%**，低於 §6.3 訂的
28.0% 門檻。

管線本身沒問題：§6.3 的三條基準線逐位重現（24.0% / 24.0% / 28.0%），
評鑑 join 1,101/1,101，正樣本 128 與特徵檔逐筆相符。

從「所有子指標百分位直接加權」逐步換成 §5 的維度管線，一次只改一件事：

| 步驟 | 改了什麼 | P@50 |
|---|---|---|
| ① | 扁平加權所有子指標百分位（評鑑實際佔 62%） | 28.0% |
| ② | 改成維度平均 + §5.0 權重（先不含輿情） | 22.0% |
| ③ | ② + 加入輿情 21.4% | 20.0% |
| ④ | ③ + 覆蓋率重正規化（§5.1 原文） | 20.0% |
| ⑤ | ④ + 同儕群內百分位（§5.2 原文） | 20.0% |

**零膨脹百分位、覆蓋率加權、組內 ECDF 三個 v2 招牌設計對 P@50 完全中性。**
掉分的是權重表與輿情維度。

## 決策

### 一、輿情維度不計入風險分數

`WEIGHTS` 的 `sentiment` 設為 `None`。

**依據**：該維度單獨 Precision@50 = **8.0%**，低於隨機抽查的 10.9%。
只看 L2 區級熱度也是 8.0%。有 B 級輿情訊號的 11 個行政區共 867 園，
被罰率 **10.5%**，與全市 10.9% 無異。

事後看是合理的：板橋區有 162 家幼兒園，一則「板橋某幼兒園」的報導
不會讓其中任何一家更可能在明年被裁罰。§5.5 把 L2 設計成撐起覆蓋率的主力，
而它撐起來的確實是覆蓋率——不是準確度。

**不是刪除輿情功能**。資料照常產出，`media` 區塊、行政區熱力圖、
`park_risk.json` 全部保留。

`dimensions.sentiment` 的契約設為 `applicable: false` + `score: null` +
`note`，**不是因為它真的不適用**，而是 `FRONTEND.md` 對 `applicable: false`
的渲染規則（顯示「——」與 note 文字、不畫成 0 分也不畫成載入中）
正好就是這裡要的行為。設成 `true` 而 `score: null` 會落進前端沒有定義的狀態。
`coverage` 仍照實回報資料可得性（多數園 0.4，代表只有 L2 有訊號），
讓「為什麼不計分」在 API 層面就看得出來。

L1 園級訊號切點前只覆蓋 14 園，樣本太小談不上有效或無效，
等補標完成後可重新量測再決定是否納回。

### 二、違規 : 評鑑 改為 38 : 62

原表私立是 違規 50% / 評鑑 28.6%。

**依據**：§6.3 第 4 列那條實測 28.0% 的基準線，公式是
`裁罰次數 + 2×基礎評鑑未通過 + 3×行政處分`——**評鑑實際佔約 62% 的權重**。
而單獨量測是評鑑 26.0%、違規 24.0%，評鑑較強。

§5.0 的權重表把最大權重給了較弱的維度，與規格自己最好的那條基準線矛盾。
**兩者衝突時以實證那邊為準。**

> §4.1 說違規是「全案最強的維度」，那是指 lift（有無裁罰的被罰率差異），
> 不是 top-50 的排序能力。違規次數能把「曾被罰」與「沒被罰」分開，
> 但在曾被罰的 400 多家內部再排序時，評鑑帶的資訊更準。這兩件事不一樣。

公立與非營利保留營運 30%，其餘 70% 依同一個 38:62 分配
（違規 26.6% / 評鑑 43.4%）。

### 三、「不適用」與「有資料缺口」分開處理

`R_raw` 的分母由 `Σ(w_k · Coverage_k)` 改為 **`Σ(w_k)`，只算適用的維度**。

| 情況 | 例子 | 處理 |
|---|---|---|
| **不適用** | 私立沒有營運維度（依法不需公告財報） | 退出分母 |
| **有資料缺口** | 137 園查無切點前評鑑紀錄 | **留在分母**，貢獻按覆蓋率打折 |

**依據**：§5.1 原文把兩者一視同仁。結果是一家只有裁罰分數、查無評鑑紀錄的園，
整份分數由違規維度單獨決定並被放大到滿分基準——「沒資料」被當成「不適用」。

實測那 101 園被罰率 **7.9%**，低於母體的 10.9%，卻被這個機制推進 top-50
佔掉 **11 個名額、只命中 1 家**。

改成分母固定後 P@50 從 24.0% 回到 26.0%，且**不需要任何調出來的常數**
（固定給缺失維度 20 分也是 26.0%，兩者同分——所以採用沒有魔術數字的那個）。

### 四、門檻 28.0% 的來歷要寫進簡報

**不降低門檻，但要說明它是怎麼來的。**

28.0% 是 §6.3 第 4 列那條**用原始次數直接相加**的手算排序的成績，
權重 1:2:3 是手挑的。它是 v1 方法的數字。

§6.3 自己的註腳寫著：「上表第 4、5 列是原始值直接加權（v1 做法）。
v2 改用零膨脹百分位後，同一排序的 Precision@50 是 **26.0%**」，
下一句是「門檻仍訂在 28.0%」。

**等於拿 A 方法的成績，去要求 B 方法達標，而規格自己已經記下 B 方法會低 2 點。**
本次實測的 26.0% 正好落在 §6.3 註腳自己預告的數字上。

> README 首頁「比隨機抽查準 2.65 倍」也是這條手算基準線的數字
> （28.0% ÷ 10.6% = 2.64），不是模型的成績。模型的數字是 26.0% / **2.39x**，
> 兩處文案要一起改。

## 結果

| | 修改前 | 修改後 |
|---|---|---|
| Precision@50 | 20.0% | **26.0%** |
| Precision@20 | 25.0% | **40.0%** |
| lift@50 | 1.84x | **2.39x** |

26.0% 對 28.0% 的差距是 **top-50 命中 13 家 vs 14 家，一家園**。
簡報口徑「同樣 50 家，隨機抓 5 家、我們抓 13 家」完全成立。

## 沒有採納的選項

**改回原始值加權拿 28.0%**——要放棄跨類型可比性與抗離群值，
而那正是 v2 存在的理由（§5.0 決議 3）。且 §5 已凍結、其他三軌照它出貨。

**降低門檻到 26%**——§6.3 明文禁止「降低標準」。本 ADR 不動門檻，
改為說明門檻的量測方法與模型的量測方法不同，這是誠實且可辯護的講法。

**把近期性加進違規維度**——試過，P@50 從 26.0% 掉到 24.0%，不採納。

## 營運維度：無法驗證，不是有害

營運維度只作用在公立與非營利兩組（私立 `applicable = false`）。
公立組隨本 ADR 的修正由 lift 1.71x 升到 2.56x；非營利組 P@10 = **0.0%**。

**那個 0.0% 不能讀成「營運維度有害」。** 換 K 就翻過來——P@15 是 1.01x、
**P@20 是 1.51x**、P@30 是 1.26x。被裁罰的 7 家在組內排 13、14、17、19、
29、32、53 名，**擠在第 10 名門檻外面一點點**；排序沒有顛倒，是 K = 10
這條線正好切在它們前面（`backtest.py` 對小樣本組自動用較小的 K）。

用超幾何分布算，**隨機排序拿到「前 10 名 0 命中」的機率是 20.9%**。
丟銅板也有五分之一的機會拿到這個結果。

結論與 §5.6.8 一致且未被改變：有財務資料的 33 園中被裁罰過的只有個位數，
**任何 K 的結果都在雜訊裡**。`validated` 一律 `false`。簡報**既不要講
「補上了監督式模型的洞」，也不要講它有害**——兩邊都沒有證據。

## 一個必須一起講的量級問題

母體 1,178、正樣本 128、K = 50 —— **top-50 裡多命中 1 家就是 2 個百分點。**
本 ADR 裡 2 點以內的差異都在雜訊範圍，不該當選型依據。
真正超出雜訊的只有兩件事：①→② 的 6 點（權重表）與輿情的 8.0% vs 10.9%。
